# Luma 0.4.13 — актуальный релиз для macOS

Релиз объединяет завершённую фазу 0.4, восемь языковых пакетов и работу с обычными
изображениями. Приложение, установочный том и версия в интерфейсе оформлены для Luma.

## Что нового

- Иконка приложения и тома DMG с золотым логотипом Luma.
- Адаптивная компоновка batch-кнопок и фильтров Library на небольших экранах.
- Единая версия в Settings, заголовке окна, строке состояния, Finder и --version.
- English по умолчанию; Russian, Simplified Chinese, Armenian, German, Spanish,
  Italian и French переключаются в Settings без перезапуска. Выбор сохраняется.
- RAW и JPEG/PNG/TIFF8/16/HEIC/HEIF/WebP/BMP/GIF; AVIF при наличии системного decoder.
  ICC, EXIF orientation и прозрачность проходят через общий Develop pipeline.
- Curves/HSL, targeted adjustments, восемь готовых фильтров, пользовательские presets,
  subset Copy/Paste, batch Paste/Sync/presets и Undo/Redo.
- Detail sharpening/noise reduction, Crop/straighten, calibrated Lens Corrections,
  manual/Auto/Guided Transform и thumbnails с сохранёнными правками.
- Экспорт JPEG/PNG/TIFF8/16/processed Linear RGB DNG; sRGB/Display P3/Adobe RGB/
  ProPhoto, resize, output sharpening, metadata/privacy, watermark и очередь.
- Library Add/Copy, дубликаты, оценки/флаги/метки/коллекции, автосохранение и restart.
- Колокольчик обновлений со Sparkle и проверкой подписи архива; установка ждёт
  сохранения правок и завершения активных операций.

## Установка

macOS 14+ и Apple Silicon (arm64). Qt SDK и Homebrew не нужны.

Скачайте `Luma-0.4.13-macos-arm64.dmg`, откройте его и перенесите Luma в Applications.
Также доступен ZIP. Версия видна в Settings и нижней строке приложения.
Сборка имеет ad-hoc подпись; Developer ID и notarization пока отсутствуют.
macOS может потребовать разрешить первый запуск через Privacy & Security → Open Anyway.

`SHA256SUMS` содержит checksums DMG, ZIP, BUILD_INFO.json и appcast.xml.
`BUILD_INFO.json` фиксирует точный исходный commit, платформу и зависимости.
Appcast подписан Ed25519 для встроенного в Luma публичного ключа.

## Ограничения

- Поддерживаемый sensor RAW — integer Bayer; X-Trans, monochrome и общий RGB/float
  DNG не поддержаны. Reimport доступен для собственного processed Linear RGB DNG.
- Reference bilinear demosaic; нет production camera profiles/highlight reconstruction.
- GIF — первый кадр, TIFF — первая страница, HEIF — primary image. HDR gain maps,
  animation/multi-page editing и auxiliary depth/matte не входят в этот релиз.
- PNG/TIFF сохраняют прозрачность; JPEG/DNG сводят её на чёрный фон.
- Undo/Redo ограничен текущей сессией. Нет локальных масок, Metal pipeline, AI,
  XMP/relink/backup workflow или сертификации больших фотокаталогов.
- Catalog schema 9/edit schema 8 несовместимы с ранними версиями. Перед обновлением
  важного каталога сохраните резервную копию при закрытом приложении.
- Intel, Windows и Linux не поддерживаются.

Фаза 0.5 не начата. Оригиналы фотографий остаются неизменными.
