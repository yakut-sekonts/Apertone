# Luma 0.4.0 — Curves, HSL и обновления macOS

Первый подэтап расширенной обработки: кривые и HSL с сохранением правок,
Undo/Redo и воспроизводимым экспортом. Приложение работает локально,
без аккаунта и облачной обработки фотографий.

## Новое

- Точечные кривые RGB, Red, Green и Blue: добавление, перемещение и удаление точек.
- Параметрическая кривая: Shadows, Darks, Lights и Highlights.
- HSL по восьми цветовым диапазонам: Hue, Saturation и Luminance.
- Targeted tools: изменение тона или цвета жестом непосредственно по фотографии.
- Отдельное включение Curves/HSL; один жест соответствует одной операции Undo.
- Одинаковая обработка в preview и JPEG/PNG/16-bit TIFF; автосохранение и restart.
- Колокольчик: уведомление о новой версии, ручная проверка и настройка ежедневных проверок.
- Установка подписанного обновления через Sparkle без ручной замены `.app`.
  Перезапуск ждёт успешного сохранения правок и завершения активных операций.

## Установка и переход с v0.3.0

macOS 14 или новее, Apple Silicon (arm64). Qt SDK и Homebrew для запуска не нужны.

Скачайте `Luma-0.4.0-macos-arm64.dmg` и перенесите Luma в Applications.
Альтернатива — распаковать ZIP и перенести `Luma.app`.
Перед заменой приложения закройте Luma. v0.3.0 не содержит updater и требует
этого ручного перехода; дальнейшие версии устанавливаются через колокольчик.

Сборка имеет ad-hoc подпись, без Developer ID и notarization.
Для первого запуска может потребоваться System Settings → Privacy & Security
→ Open Anyway. [Пояснение Apple](https://support.apple.com/en-ie/102445).
EdDSA-подпись архива обновления проверяется отдельно и не заменяет notarization.

Каталог мигрирует со схемы 3 на 4. Существующие Library-данные, выбранная фотография
и базовые правки сохраняются; исходные RAW остаются неизменными.
После миграции v0.3.0 не откроет этот каталог. Перед переходом сохраните резервную
копию каталога при закрытом приложении; автоматический downgrade не предусмотрен.

`SHA256SUMS` содержит checksums ZIP, DMG, `BUILD_INFO.json` и `appcast.xml`.
Проверка скачанных файлов: `shasum -a 256 -c SHA256SUMS`.
Манифест сборки фиксирует исходный commit и версии зависимостей.

## Проверки

- macOS Apple Silicon: сборка, 13 CTests, clang-format и clang-tidy.
- Curves/HSL: GUI gestures, targeted tools, Undo/Redo, транзакционные сбои записи,
  миграция, перезапуск и одинаковый PNG/TIFF экспорт.
- Локальная проверка Nikon D7500; приватный NEF не публикуется и не включён в CI.
- Каталог, созданный настоящей v0.3.0: миграция сохраняет побайтно одинаковый PNG.
- Автономный `.app` запускается с недоступными Qt SDK и исходной папкой Sparkle.
- Реальная установка и перезапуск Sparkle проверены на изолированном приложении
  с отдельным тестовым ключом. Проверки также отклоняют изменённые архивы.

## Ограничения

Это первый подэтап 0.4. Готовые пресеты, Detail/noise reduction, Crop, Optics,
локальные маски и Metal processing ещё не реализованы.
Curves/HSL используют определённую проектом обработку в perceptual sRGB;
это не Adobe processing engine и не калиброванные camera profiles.

Поддержаны integer Bayer RAW, включая проверенные Nikon NEF и Bayer DNG.
X-Trans, monochrome RAW, RGB/float DNG и JPEG/HEIF ingestion остаются позже.
Undo/Redo хранится в текущей сессии; Library thumbnails показывают оригинал.
Экспорт — исходное разрешение и sRGB, без исходных EXIF/GPS.
Move, smart collections, XMP, batch export, relink и автоматические backups
пока отсутствуют. Intel Mac, Windows и Linux вне текущего поддерживаемого scope.
