# Apertone 1.3.1

Apertone 1.3.1 adds an Intelligent Library for a faster first pass through an
import. Analysis is optional, runs locally on the Mac and leaves original files
unchanged.

## Intelligent Library

- Analyze the current selection or all pending Library photos.
- Optionally analyze new imports automatically. The setting is off by default.
- Review explainable Pick, Review and Reject suggestions. Photo cards identify
  soft focus, exposure issues, low face quality and closed eyes when detected.
- Apply suggestions only to unflagged photos in the current selection or active
  Library filters. Existing manual Pick and Reject flags are preserved.
- Filter to the strongest suggested frame in each detected burst.
- Filter and name groups of visually similar faces. These groups are local
  similarity suggestions and do not claim to recognize a person's identity.

## Local data and compatibility

The same RAW and ordinary-image decoder used by Develop supplies oriented
previews to the analyzer, so the workflow covers the camera and image formats
supported by Apertone. No photo, descriptor or group name is uploaded.

Catalog schema 22 stores versioned derived analysis and creates a restorable
pre-migration backup. Results are ignored when an original checksum changes.
A model/provider change requires an explicit clear and rebuild, avoiding silent
loss of named groups. Clear Analysis removes the active catalog index; existing
catalog backups can still retain earlier analysis until their normal retention
period expires.

## Install

Requires macOS 14 or later on Apple Silicon. Download
`Apertone-1.3.1-macos-arm64.dmg`, drag Apertone to Applications and open it.
The open-source build is ad-hoc signed and is not Apple-notarized. If Gatekeeper
blocks the first launch, Control-click Apertone, choose Open, then confirm Open.

Existing installations receive 1.3.1 through the update bell. The release also
provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest and build
provenance.
