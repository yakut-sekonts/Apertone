# Apertone 2.5.0

Apertone 2.5 brings the 2.1–2.5 development work together in one release.

- Organize user presets in nested folders and move or rename folder trees.
- Import Texture, Clarity2012 and Dehaze from Camera Raw XMP presets as sparse
  Presence adjustments. Rendering does not promise identical Adobe pixels.
- Include camera, lens, ISO and capture time in export filenames, with explicit
  fallbacks when metadata is missing.
- Preserve each affected photo's editing history across batch Apply, Paste,
  Sync, Undo and Redo and application restart. The batch journal remains
  session-local.
- Review matching stored import-time fingerprints in the Library. A match is
  not proof that current files are identical: originals can change or become
  unavailable after import. The review does not modify originals.

Requires macOS 14 or later on Apple Silicon. The GitHub distribution uses an
ad-hoc signature and is not Apple-notarized. Download the DMG from the release,
move Apertone to Applications and open it. The release also provides a signed
Sparkle update ZIP, appcast, SHA-256 manifest and build information.

## Windows x64

Apertone supports Windows 10 and 11 x64. Extract the Windows ZIP to a folder
such as `E:\Apertone` and launch `Apertone.exe`. Keep the files from the ZIP
together. [Apertone 2.5.0 release](https://github.com/yakut-sekonts/Apertone/releases/tag/v2.5.0)

- Migrate Lightroom Classic catalogs with supported Develop settings, virtual
  copies, collection-set paths, keyword paths and dynamic Smart Collections.
  Preview per-photo XMP with the source
  process version and a list of unsupported settings.
- Organize photos into manual stacks with a cover. Keep a Develop reference
  pinned while switching photos and open an independent review window.
- Prepare offline previews for a Library selection and repair truncated preview
  files. Import from a mounted DCIM card or watch the folder written by a
  tethered capture application.
- Develop X-Trans and monochrome RAW through LibRaw. Edit an eight-channel B&W
  mix, primary color calibration, defringe and localized red eye.
- Select a subject, background, clicked object, sky, people, facial regions
  and a relative depth range locally. Denoise a RAW in a separate Linear DNG
  with model provenance.
- Apply descriptive and camera metadata policies to SDR JPEG, PNG, TIFF and
  Linear DNG. Export sRGB Ultra HDR JPEG and profiles for standard formats,
  including 8-bit and 16-bit ZIP TIFF.
- Create contact sheets or photo books in PDF, preview with an RGB proof ICC
  profile, and save a local HTML gallery or slideshow. View EXIF locations on a
  bundled offline map.
- Use the Apertone icon in Explorer, shortcuts and the running window.

The local models use the Microsoft Visual C++ x64 Redistributable.
Windows catalogs use schema 26. Apertone creates a backup before upgrading an
existing catalog. [Microsoft downloads](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)

Depth masks use relative estimates. Facial region masks use feathered regions
located by facial landmarks. Direct camera control, physical exFAT qualification,
printer calibration, full Lightroom metadata and mask interchange, and remote
Publish Services are tracked in the compatibility backlog.
