# Apertone 2.5.0

Apertone 2.5 brings the 2.1–2.5 development work together in one release.

- Organize user presets in nested folders and move or rename folder trees.
- Import Texture, Clarity2012 and Dehaze from Camera Raw XMP presets as sparse
  Presence adjustments. Rendering does not promise identical Adobe pixels.
- Include camera, lens, ISO and capture time in export filenames, with explicit
  fallbacks when metadata is missing.
- Preserve each affected photo's editing history across batch Apply, Paste,
  Sync, Undo and Redo and application restart. The batch journal remains
  session-local.
- Review matching stored import-time fingerprints in the Library. A match is
  not proof that current files are identical: originals can change or become
  unavailable after import. The review does not modify originals.

Requires macOS 14 or later on Apple Silicon. The GitHub distribution uses an
ad-hoc signature and is not Apple-notarized. Download the DMG from the release,
move Apertone to Applications and open it. The release also provides a signed
Sparkle update ZIP, appcast, SHA-256 manifest and build information.
