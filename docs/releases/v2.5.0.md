# Apertone 2.5.0

Apertone 2.5 brings the 2.1–2.5 development work together in one release.

- Organize user presets in nested folders and move or rename folder trees.
- Import Texture, Clarity2012 and Dehaze from Camera Raw XMP presets as sparse
  Presence adjustments. Rendering does not promise identical Adobe pixels.
- Include camera, lens, ISO and capture time in export filenames, with explicit
  fallbacks when metadata is missing.
- Preserve each affected photo's editing history across batch Apply, Paste,
  Sync, Undo and Redo and application restart. The batch journal remains
  session-local.
- Review matching stored import-time fingerprints in the Library. A match is
  not proof that current files are identical: originals can change or become
  unavailable after import. The review does not modify originals.

Requires macOS 14 or later on Apple Silicon. The GitHub distribution uses an
ad-hoc signature and is not Apple-notarized. Download the DMG from the release,
move Apertone to Applications and open it. The release also provides a signed
Sparkle update ZIP, appcast, SHA-256 manifest and build information.

## Windows x64

Apertone supports Windows 10 and 11 x64. Extract the Windows ZIP to a folder
such as `E:\Apertone` and launch `Apertone.exe`. Keep the files from the ZIP
together. [Apertone 2.5.0 release](https://github.com/yakut-sekonts/Apertone/releases/tag/v2.5.0)

- Migrate Lightroom Classic catalogs with supported Develop settings, edit
  history, named snapshots, virtual copies, nested collection sets, keyword
  hierarchies and dynamic Smart Collections. The importer reports partially
  converted and skipped Develop states. Per-photo XMP preview shows the process
  version and unsupported settings.
- Transfer saved bitmap masks and compatible linear gradients from a Lightroom
  Classic catalog kept beside its `.lrcat-data` folder. Local tone and
  saturation corrections transfer with supported masks. The import report
  counts converted and skipped masks. Apertone can look up a matching saved
  mask in the photo's Develop history and snapshots. The importer can also
  rebuild compatible missing subject, sky, face and lip masks with local models
  and marks those layers `[AI rebuilt]`. A repeat import can save a processing
  version for a photo Apertone already manages.
- Load a DNG camera profile (`.dcp`) in Develop. In the Lightroom importer,
  select a folder of DNG camera profiles to match their names and camera models
  to RAW photos. Apertone stores applied profiles in its catalog and uses them
  for preview and export.
- Create and move collection sets, organize regular and Smart Collections
  inside them, and manage keyword hierarchies. Assign keywords to selected
  photos and find them by their aliases.
- Organize photos into manual stacks with a cover. Keep a Develop reference
  pinned while switching photos and open an independent review window.
- Prepare offline previews for a Library selection and repair truncated preview
  files. Import from a mounted DCIM card or watch the folder written by a
  tethered capture application.
- Trigger a still photo from **Library → Tethered camera** on Windows if
  the camera driver exposes WPD still-image capture. Apertone saves the
  newly captured RAW and JPEG files to the selected folder and imports them.
- Connect a supported camera in that dialog to adjust shutter speed, aperture,
  ISO and exposure compensation using its reported settings. Nikon cameras
  that expose Live View through the Windows PTP/MTP driver can stream a preview.
- Develop X-Trans and monochrome RAW through LibRaw. Edit an eight-channel B&W
  mix, primary color calibration, defringe and localized red eye.
- Select a subject, background, clicked object, sky, people, facial regions
  and a relative depth range locally. Denoise a RAW in a separate Linear DNG
  with model provenance.
- Apply descriptive and camera metadata policies to SDR JPEG, PNG, TIFF and
  Linear DNG. Export sRGB Ultra HDR JPEG and profiles for standard formats,
  including 8-bit and 16-bit ZIP TIFF.
- Create contact sheets or photo books in PDF, preview with an RGB proof ICC
  profile, and save a local HTML gallery or slideshow. View EXIF locations on a
  bundled offline map. Windows offscreen PDF export uses installed fonts and
  embeds the glyphs for titles, filenames and page numbers.
- Publish an HTML gallery of edited JPEGs to a new folder on an HTTPS WebDAV
  server from **Library → Deliver selected photos**. The destination must
  support `MKCOL`, `PUT` and `MOVE`. Credentials are entered for each attempt.
- Use the Apertone icon in Explorer, shortcuts and the running window.

The local models use the Microsoft Visual C++ x64 Redistributable.
Windows catalogs use schema 28. Apertone creates a backup before upgrading an
existing catalog. [Microsoft downloads](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)

Depth masks use relative estimates. Facial region masks use feathered regions
located by facial landmarks. History import keeps up to 200 recorded steps and
the active edit per photo. Snapshot import uses the existing limit of 100 saved
versions per photo. Lightroom masks depend on payload availability and supported
geometry. Other face and body subregions with missing mask pixels, historical
mask rendering and Adobe XMP looks remain open. Camera and driver compatibility,
physical exFAT SD cards and paper print calibration still require device tests.
