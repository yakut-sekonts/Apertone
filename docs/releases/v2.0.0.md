# Apertone 2.0.0

Apertone 2.0 combines the Camera Fidelity, Intelligent Library, Persistent
Workflow, and Detail/Resolution work into one local-first release. There are no
intermediate 1.7, 1.8, or 1.9 releases.

## Camera fidelity

- Normalize Bayer data with validated per-channel sensor limits and recover
  partially clipped camera-linear highlights before White Balance and the color
  transform.
- Preserve measured sensor headroom for fully clipped pixels instead of
  inventing color.
- Resolve embedded dual-illuminant DNG profiles for the active White Balance,
  including `ColorMatrix`, `CameraCalibration`, `AnalogBalance`,
  `ForwardMatrix` and the specified Bradford fallback.
- Share the resolved camera gains and color matrix across CPU and Metal paths.

## Intelligent Library

- Keep local culling signals inspectable and confidence-aware. Missing Vision
  eye or face-quality observations do not count as negative evidence.
- Review skipped byte-for-byte duplicates together with the retained catalog
  original without deleting either file.
- Keep visual grouping bounded and provider-versioned; it is never presented as
  exact identity.

## Persistent workflow

- Preserve up to 200 per-photo Undo/Redo operations and the current cursor
  across restart.
- Commit the current edit document and its history in one SQLite transaction.
- Reject oversized, corrupt, duplicate or mismatched history states.
- Upgrade existing catalogs to schema 23 through the transactional migration
  and pre-migration backup path. Originals remain unchanged.

## Detail and resolution

- Create managed Float DNG results for Raw Details and deterministic 2× Detail.
- Recover bounded lens blur with an explicit local deconvolution approximation;
  this operation is not presented as ML reconstruction.
- Suppress high-frequency color moiré in smooth-luminance areas while
  preserving luminance and alpha.
- Estimate editable luminance and color noise controls from locally flat image
  regions with a conservative ISO prior in one Undo step.
- Compare the neutral and active Develop states with a draggable split, linked
  zoom and pan, Fit and full-resolution 100% rendering.
- Record provider, algorithm version, parameters, source checksums and exact
  linear input/output contracts for every derived Detail image.

All processing remains on the Mac. No account or cloud service is required.

## Install

Requires macOS 14 or later on Apple Silicon. Download
`Apertone-2.0.0-macos-arm64.dmg`, drag Apertone to Applications and open it.
The open-source build is ad-hoc signed and is not Apple-notarized. If Gatekeeper
blocks the first launch, Control-click Apertone, choose Open, then confirm Open.

Existing installations receive 2.0.0 through the update bell. The release also
provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest and build
provenance.
