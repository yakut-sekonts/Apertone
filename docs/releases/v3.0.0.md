## Apertone 3.0.0

Apertone 3.0 brings the shared photo workspace to Windows x64 and macOS on
Apple Silicon. Both packages are built from the same Git revision and are
published together after platform checks pass.

### Library and Develop

- Move between Grid, Loupe, Compare, Survey and Develop with **G**, **E**,
  **C**, **N** and **D**. Loupe opens a rendered photo for review and keeps
  the editor separate. Compare can pair the selected photo with an adjacent
  one. Survey works with the selected set and lets you narrow the review.
  The filmstrip stays available while reviewing a photo in Loupe or Develop.
  The Library can sort by filename, capture time or rating.
- Use **Y** for Before/After, **R** for Crop and **W** for the white-balance
  eyedropper in Develop. **Z** toggles 100% zoom. The View menu lists controls for the workspace header,
  filmstrip, side panels and view toolbar.
- Develop groups related adjustments in collapsible sections. The Apertone
  theme, presets, edit history and existing catalog workflows carry forward.
- Use virtual copies, stacks, Smart Collections, offline previews, and
  catalog migration with compatible Lightroom Classic settings and history.

### Migration, search and delivery

- Import compatible Lightroom Classic radial mask geometry alongside saved
  bitmap masks and linear gradients. Apertone reports masks it cannot recover.
- Use compatible external RGB DCP camera profiles with one, two or three
  illuminants. Embedded three-illuminant DNG calibration remains outside
  this support.
- Find photos with people or sky on Windows using local category search. The
  macOS search and Windows category search use platform-specific providers.
- Windows Ultra HDR JPEG exports keep supported camera, lens and descriptive
  metadata in XMP according to the selected export policy. The SDR rendition
  and HDR gain map remain readable by compatible applications.
- Print contact sheets and photo books with the operating system's printer
  dialog, or export PDF with optional ICC soft proof.
- Publish or update HTML galleries on WebDAV. Updates keep the public gallery
  URL and retain the previous revision. The server must honor strong ETags
  and conditional writes. Keep the `<catalog>.luma-webdav` ownership receipts
  beside the catalog. Publish older galleries to a fresh folder before using
  Update.
- Windows tethering offers capture, Live View and exposure controls when the
  camera exposes those features through its supported driver. Developer
  ID builds for macOS can trigger still capture when the camera advertises
  native shutter support. In the GitHub ad-hoc build, use a watched folder
  to import captures.

### Download and update

- **Windows 10 or 11 x64** — Extract
  `Apertone-3.0.0-windows-x64.zip` and run `Apertone.exe`. Use the bell
  in Apertone to check for updates. Local AI inference uses the
  [Microsoft Visual C++ x64 Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).
- **macOS 14 or later on Apple Silicon** — Open the DMG and drag Apertone
  into Applications. See the [first-launch guide](../OPEN_SOURCE_RELEASE.md)
  for ad-hoc signed GitHub downloads. In-app updates use the signed Sparkle
  feed and release ZIP.
- Verify downloads with `SHA256SUMS` for macOS or `SHA256SUMS-windows.txt`
  for Windows. Apertone backs up catalogs before schema upgrades.

The [compatibility backlog](../LIGHTROOM_PARITY.md) documents Lightroom
variants, device capabilities and platform-specific coverage. Test hardware,
printer profiles and migrated edits on representative photos before relying
on them for production.
