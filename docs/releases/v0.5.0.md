# Luma 0.5.0 — локальные градиентные маски

В Develop → Local adjustments появились линейные и радиальные маски.

- Локальные Exposure, Contrast, Highlights, Shadows, Whites, Blacks, Vibrance и Saturation.
- Рисование и редактирование маски на снимке, поворот радиальной маски.
- Feather, Mask opacity, Invert, имя, включение, порядок слоёв и удаление.
- Цветное наложение с выбором цвета и прозрачности; один жест — один Undo/Redo.
- Сохранение после перезапуска, экспорт и обработанные миниатюры Library.
- Панель переведена на все восемь языков приложения.

Глобальные пресеты, XMP, Paste и Sync сохраняют имеющиеся маски снимка.
Наложение служит только для просмотра и не попадает в экспорт.

Это первый этап фазы 0.5. Brush, диапазоны цвета/яркости, boolean-операции и
перенос масок через пресеты будут добавлены далее. Доступно до 128 масок на снимок.

Catalog обновляется с версии 9 до 10; обработка и оригиналы сохраняются.
Перед обновлением сохраните копию каталога, если нужен откат на 0.4.x: старая
версия не открывает catalog 10. Автоматический backup пока не реализован.

macOS 14+, Apple Silicon. Сборка с ad-hoc подписью, без Developer ID/notarization;
первый запуск может потребовать Privacy & Security → Open Anyway.
Обновления через колокольчик проверяют Ed25519-подпись Sparkle.

Подробнее: [маски, ограничения и проверки](https://github.com/yakut-sekonts/Luma/blob/main/docs/LOCAL_ADJUSTMENTS.md).
