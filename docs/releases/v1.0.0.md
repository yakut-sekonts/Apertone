# Luma 1.0.0

Luma 1.0.0 is the first complete open-source release of the planned macOS photo
workflow. It runs locally on Apple Silicon with macOS 14 or later and does not
require an account or cloud service.

## Main capabilities

- Non-destructive RAW and common image editing with full-resolution JPEG, PNG,
  TIFF and DNG workflows.
- Light, color, curves, HSL, Presence, Point Color, Color Grading, vignette,
  grain, Detail, optics, transform and crop tools.
- Brush, linear/radial gradients, range masks, editable AI Subject/Background/
  Object/Sky masks, retouching and local adjustments.
- Bundled offline Core ML Denoise and Sky models, local semantic search,
  HDR merge and panorama merge.
- Catalogs, collections and Smart Collections, advanced Add/Copy/Move import,
  metadata/XMP, XMP preset import, relinking, backups/recovery, versions and
  session History.
- English, Russian, Chinese, Armenian, German, Spanish, Italian and French UI.
- Sparkle updates from the notification bell with an Ed25519-signed archive.

## Release acceptance

The project owner approved publication on 2026-10-26 with two explicit
exceptions: the remaining unadapted QA inventory and installed-app/end-to-end
update validation are deferred. These skipped checks are not counted as PASS.
APP016 is accepted from the owner's manual confirmation that the window minimizes
correctly. BUG045 was fixed by replacing an invalid stable-preview-URL assertion
with strict current URL/QML binding, final-render and exact-pixel coherence; its
targeted regression passes 20/20 Cocoa/Metal and 20/20 offscreen repetitions.

The published artifacts are produced only after the release workflow verifies
the exact source revision, bundled models, implemented functional/stress checks,
static analysis, standalone bundle, DMG/ZIP identity, checksums, Sparkle signature
and uploaded assets.

## Installation

Download `Luma-1.0.0-macos-arm64.dmg`, drag Luma to Applications and open it.
This community build is ad-hoc signed and is not Apple-notarized. On first launch,
macOS may require **System Settings → Privacy & Security → Open Anyway**.

Before opening an existing catalog, keep a backup. Catalog migrations are
forward-only and older Luma versions may not read the upgraded schema. Original
photo files remain unchanged by non-destructive editing.
