# Luma 0.4.14 — импорт XMP-пресетов

В Develop → Presets → Import теперь можно выбрать `.xmp` из Lightroom / Camera Raw.
Импорт сохраняет пресет в локальную коллекцию; нажмите на него для применения.

- Light, WB, Curves, HSL, sharpening и noise reduction преобразуются в настройки Luma.
- Отсутствующие в XMP параметры остаются прежними, включая настройки внутри одной группы.
- Hover preview, один Undo/Redo, batch-обработка и сохранение после перезапуска.
- Имя и папка из XMP; экспорт и повторный импорт через Luma JSON сохраняют выбор параметров.
- Диалог XMP compatibility показывает неподдерживаемые свойства.

Обработка Luma отличается от Adobe. Профили, LUT/looks, маски, calibration,
геометрия, Texture/Clarity/Dehaze и AI не импортируются. Значения за пределами
допустимых диапазонов и повреждённые XMP отклоняются целиком.

Установка: macOS 14+, Apple Silicon. Скачайте `Luma-0.4.14-macos-arm64.dmg` и
перенесите приложение в Applications либо установите обновление через колокольчик.
Сборка имеет ad-hoc подпись; Developer ID и notarization пока отсутствуют.
Первый запуск может потребовать Privacy & Security → Open Anyway.

`SHA256SUMS` содержит checksums установщика, ZIP, BUILD_INFO.json и appcast.xml.
Обновление Sparkle проверяет Ed25519-подпись архива.

Коллекция со sparse XMP-пресетами использует preset schema 7 и не открывается
старыми версиями приложения. Перед откатом сохраните `presets.json`.
Catalog schema 9 / edit schema 8 не менялись. Оригиналы остаются неизменными.
Подробнее: [XMP presets](https://github.com/yakut-sekonts/Luma/blob/main/docs/XMP_PRESETS.md).
