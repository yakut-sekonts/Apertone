# Apertone 1.1.1

This patch completes the public rename introduced in 1.1.0. The application
chrome and Develop workspace marker now consistently display Apertone, and the
CLI help uses the `apertone` executable name.

The repository description and current screenshots were refreshed to match the
shipping interface. Internal compatibility identifiers remain unchanged so
existing catalogs, settings, presets, XMP data and Sparkle updates continue to
work in place.

## Install

Requires macOS 14 or later on Apple Silicon. Download
`Apertone-1.1.1-macos-arm64.dmg`, drag Apertone to Applications and open it.
The open-source build is ad-hoc signed and is not Apple-notarized. If Gatekeeper
blocks the first launch, Control-click Apertone, choose Open, then confirm Open.

Existing installations receive 1.1.1 through the update bell. The release also
provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest and build
provenance.
