# Apertone 1.1.0

Apertone is the new name of Luma. This release combines the rename, a new original
split-tone aperture icon and the complete desktop interface redesign in one macOS
update.

## Interface

- Day uses the Framed Sheet appearance: light neutral surfaces, graphite chrome
  and a stable dark photo canvas.
- Night uses the Data Terminal appearance: compact dark surfaces with restrained
  teal and copper accents.
- System follows the current macOS appearance. The selection is available in
  Settings and persists with the catalog.
- Toolbars, sidebars, inspectors, dialogs and the filmstrip use denser controls
  designed for pointer and keyboard use on desktop displays.
- All appearance controls and messages are available in the eight bundled
  language packs.

## Upgrade compatibility

Luma 1.0 users receive Apertone 1.1.0 through the existing update bell. The bundle
identifier, Sparkle signing key and local storage identity remain stable, so the
existing catalog, settings, presets, caches and remembered catalog open in place.
Processed DNG files exported by Luma remain supported; new exports identify
Apertone.

## Install

Requires macOS 14 or later on Apple Silicon. Download
`Apertone-1.1.0-macos-arm64.dmg`, drag Apertone to Applications and open it.
The open-source build is ad-hoc signed and is not Apple-notarized. If Gatekeeper
blocks the first launch, Control-click Apertone, choose Open, then confirm Open.

The release also provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest
and build provenance. The updater verifies the ZIP with the public key embedded
in both Luma 1.0 and Apertone 1.1.0 before installation.
