# Luma 0.3.0 — первый релиз для macOS

Первый публичный релиз Luma объединяет Foundation, Develop Core и Library.
Приложение работает локально, без аккаунта и облачной обработки фотографий.

## Системные требования

- macOS 14 или новее; Apple Silicon (arm64).
- 8 GB RAM минимум, 16 GB рекомендовано.
- Qt SDK, Homebrew и инструменты разработки для запуска не нужны.

## Что работает

- Импорт RAW-файлов и папок в режимах Add/Copy, проверка SHA-256 и размера,
  пропуск дубликатов, отмена и восстановление прерванного импорта.
- Сетка Library, filmstrip, одиночное/групповое выделение, оценки 0–5,
  Pick/Reject/Unflag, цветовые метки, ручные коллекции и комбинированные фильтры.
- Декодирование данных сенсора Nikon NEF и integer Bayer DNG через LibRaw.
- As Shot/ручной WB, Temperature/Tint, Exposure, Contrast, Highlights, Shadows,
  Whites, Blacks, Vibrance и Saturation; отключение отдельных коррекций.
- Undo/Redo, сравнение с оригиналом, автосохранение и восстановление выбранного кадра.
- Экспорт JPEG, PNG и 16-bit TIFF в исходном разрешении с sRGB ICC.
- Исходные RAW-файлы остаются неизменными; метаданные и правки хранятся в SQLite.

## Установка

1. Скачайте `Luma-0.3.0-macos-arm64.dmg` и перенесите Luma в Applications.
   Альтернатива: распакуйте `Luma-0.3.0-macos-arm64.zip` и перенесите Luma.app.
2. Откройте Luma. Для первого запуска может потребоваться разрешение в
   System Settings → Privacy & Security → Open Anyway. Сборка имеет ad-hoc
   подпись; Developer ID signing и notarization пока отсутствуют.
   [Пояснение Apple](https://support.apple.com/en-ie/102445).
3. Импортируйте RAW или нажмите «Открыть RAW». Двойной клик в Library открывает Develop.

`SHA256SUMS` содержит checksums установочных файлов и `BUILD_INFO.json`.
Проверка скачанных файлов в Terminal: `shasum -a 256 -c SHA256SUMS`.
`BUILD_INFO.json` фиксирует версию, исходный commit и версии зависимостей.
Лицензии и соответствующие исходные архивы LGPL-компонентов включены в приложение.

## Проверки

- macOS Apple Silicon: сборка, CTest, clang-format и clang-tidy.
- Публичные синтетические DNG: GUI, экспорт, перезапуск, импорт, коллекции и recovery.
- Локальная проверка на Nikon D7500: метаданные, обработка, экспорт и целостность RAW.
  Приватный NEF не публикуется; в CI этот тест явно пропускается.
- Автономный bundle проверяется с недоступным Qt SDK.
- Каталог на 100k строк метаданных: постраничная модель, лимит 16×128 строк,
  выделение и фильтры. Это не сертификация производительности 100k реальных фото.

## Известные ограничения

- Integer Bayer RAW; X-Trans, monochrome RAW, RGB/float DNG и JPEG/HEIF ingestion не поддержаны.
- Reference bilinear demosaic и базовые WB/tone/color; нет готовых цветовых пресетов,
  Curves, HSL, detail/noise reduction, crop, optics, локальных масок и Metal processing.
- Undo/Redo хранится в текущей сессии; Library thumbnails показывают оригинал.
- Нет Move, smart collections, XMP, batch export, relink и автоматических backups.
- Экспорт: только sRGB, исходное разрешение, без исходных EXIF/GPS.
- Схема каталога 3 несовместима с ранними M0/Develop Core бинарниками.
  Перед обновлением важного каталога сохраните его резервную копию при закрытом приложении.
- Intel Mac, Windows и Linux пока вне поддерживаемой платформы.
