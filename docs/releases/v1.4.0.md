# Apertone 1.4.0

Apertone 1.4.0 makes repeated imports and catalog cleanup explicit, durable and
safe. Import sources can be reviewed and refreshed without rebuilding the
Library or losing existing edits.

## Import source management

- Refresh the latest completed import with its original Add, Copy or Move plan.
- Review the exact files and folders saved for each completed import, including
  their current availability and import mode.
- Refresh one source or refresh all tracked sources sequentially. Existing
  catalog items are skipped as duplicates and keep their edits and metadata.
- Forget a source association without deleting catalog photos, edits, history,
  collections or files. A forgotten newest source is no longer selected by
  Refresh last import.
- Continue reading import plans created by earlier Apertone versions.

## Clear Library

Clear Library removes catalog photos, edits, metadata, import history and local
derived analysis in one guarded operation. Original files, exported files,
catalog backups and saved collection definitions remain untouched. Collections
remain available and empty after the reset.

The command requires explicit confirmation and is unavailable while import,
export, analysis or another Library operation is active. Apertone also clears
the active editor and preview state after a successful reset.

## Install

Requires macOS 14 or later on Apple Silicon. Download
`Apertone-1.4.0-macos-arm64.dmg`, drag Apertone to Applications and open it.
The open-source build is ad-hoc signed and is not Apple-notarized. If Gatekeeper
blocks the first launch, Control-click Apertone, choose Open, then confirm Open.

Existing installations receive 1.4.0 through the update bell. The release also
provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest and build
provenance.
