# Apertone 1.2.0

Apertone 1.2.0 adds broad camera RAW support and a complete first-party Quick
Look workflow for fast, non-destructive photo development.

## Quick Looks

- 70 original looks across Recommended, Adaptive, Portrait, Seasons, Style,
  Film, Scenes, Travel and Auto+ categories.
- Multiple looks can be stacked in order. Every layer can be enabled, reordered,
  removed and adjusted from 0–200% without baking changes into the original.
- Adaptive Subject, Sky and Background looks create editable local masks and use
  the same persistent render path as manual local adjustments.
- Background looks include bounded blur rendered consistently in preview and
  full-resolution export.
- Auto, B&W and automatic perspective straightening remain available as compact
  one-click actions.

## Camera support

The shared RAW path now accepts common integer Bayer formats from Canon, Sony,
Nikon, Pentax/Ricoh, OM System/Olympus, Panasonic/Leica, Samsung, Hasselblad and
Phase One, together with Bayer DNG. Compatibility still depends on the camera
model and sensor layout. X-Trans, monochrome, Foveon/layered and general
floating-point/RGB DNG inputs are rejected explicitly rather than developed
through an embedded preview.

## Compatibility

Existing Apertone and Luma catalogs, settings, presets, masks, XMP data and
Sparkle update installations continue in place. Quick Look documents use a
versioned codec that remains compatible with documents created before 1.2.0.

## Install

Requires macOS 14 or later on Apple Silicon. Download
`Apertone-1.2.0-macos-arm64.dmg`, drag Apertone to Applications and open it.
The open-source build is ad-hoc signed and is not Apple-notarized. If Gatekeeper
blocks the first launch, Control-click Apertone, choose Open, then confirm Open.

Existing installations receive 1.2.0 through the update bell. The release also
provides the Sparkle-signed ZIP, `appcast.xml`, SHA-256 manifest and build
provenance.
