# Original raster fixtures

These tiny synthetic fixtures were created by the Luma project and are distributed
under the repository's Apache-2.0 license. They contain no photographic/private
material or third-party ICC profiles. `prepare.py` reproduces the mathematical
pixels with Pillow 11.3.0 (development fixture-generation tool only; not a runtime
or CI dependency).

- `quadrants.webp`: lossless 32×24 RGBA: opaque red, half-alpha green, transparent
  blue, opaque gray (128). SHA-256
  `e16b022b9f7b496c96737a8f36784dd780ea229b136addd469f6d43b53fd6738`.
- `two-frames.gif`: 32×24; first frame red with a blue bottom-right pixel, second
  frame green. SHA-256
  `7e08d83c76f2e1b09408e29d6c20b1ef0efe94b984d453fc325e8a4c8546c10c`.

- `opaque.heic`: 64×48 opaque red/green/blue/gray quadrants; generated using
  `swift prepare-native.swift .` on macOS (ImageIO HEIC encoder). SHA-256
  `b42a62702ec871333295a650b18fed99815f52ae7d78b58b1a28f815f2451f24`.
- `opaque.avif`: the same 64×48 opaque quadrants, generated by `prepare.py` with
  Pillow's AVIF encoder, quality 100, 4:4:4. SHA-256
  `73f7f802d5f09f6c9b1f6e82f117fdc9534cd4e705e472d5e543d4e87fbcddfb`.

Encoder bytes may vary between tool/OS versions; these hashes identify the checked-in
reference files. Optional AVIF decoding is tested only if the system advertises it.

Other format/color/orientation/precision fixtures are generated by native ImageIO
inside acceptance tests and are not redistributed. Codec capability is checked at
runtime for optional AVIF and native fixture encoders.
